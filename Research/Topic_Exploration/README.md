# Topic Exploration

## 목적
초기 연구 아이디어를 문제 정의, 선행연구, 실험 가능성에 따라 비교하고 연구 주제로 좁힙니다.

## 평가 기준
- 문제의 중요성과 구체성
- 선행연구 대비 확인 가능한 차별점
- 측정·제작·시뮬레이션 가능성
- 필요한 장비·시간·협업
- 정량화할 수 있는 성공 기준
- 논문 또는 과제 결과물과의 적합성

## 기록 원칙
- 확인된 사실, 출처의 주장, 개인적 추론을 분리합니다.
- 새로움은 원문·특허 확인 전 확정하지 않습니다.
- 여러 아이디어를 비교한 뒤 선택·보류·폐기 이유를 기록합니다.

## 연구 기록
