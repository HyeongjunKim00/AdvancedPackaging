## 기록 규칙
- 조사 전 질문과 범위를 기록하고, 사실·출처 주장·추론을 분리한다.
- 출처 링크와 근거 등급(A/B/C/추론), 원문 확인 범위, 조건을 남긴다.
- 수치가 충돌하면 하나로 합치지 말고 충돌 항목으로 기록한다.
- 대화 단위 인계 문서는 Topic_Exploration에 저장하고, 최신 작업 요약은 루트의 `AI_HANDOFF.md`에 연결한다.
